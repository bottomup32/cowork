# AI 오피스

총괄에게 일을 맡기면, 총괄이 업무를 나누고 필요한 직원을 팀에 채용해 순서대로 일을 시킨 뒤 최종 보고서로 정리하는 3D 사무실입니다.

## 바로 쓰기

- **claude.ai Artifact (권장)**: 게시된 페이지를 열면 내 Claude 계정으로 바로 동작합니다. 첫 지시를 보낼 때 Claude 사용 허용 창이 뜹니다. 팀·직원·작업 기록은 내 계정에만 비공개로 저장됩니다.
- **로컬/자체 호스팅**: `index.html`을 브라우저로 엽니다. claude.ai 밖에서는 과금할 구독이 없으므로 데모 모드(예시 흐름)로만 동작합니다. API 키 입력 경로는 두지 않습니다.

## 동작 방식

1. **지시**: 대표(사용자)가 총괄에게 일을 적어 보냅니다.
2. **계획·채용**: 총괄이 지시를 2~5개 하위 업무로 나누고, 기존 직원 중 맞는 사람을 고르거나 팀에 새 직원을 채용합니다. 맞는 팀이 없으면 새 팀을 하나 만들 수 있습니다.
3. **실행**: 직원들이 순서대로 일하고, 뒤 직원은 앞 직원 결과물을 참고합니다. 3D 사무실에서 일하는 직원의 모니터 조명과 말풍선으로 진행 상황을 볼 수 있습니다.
4. **보고**: 총괄이 결과물을 모아 한 줄 요약, 핵심 결과, 확인이 필요한 부분, 다음 단계로 정리합니다.

팀은 최대 8개, 팀당 직원은 최대 8명입니다. `작업 모드`로 속도/균형/품질(모델 등급)을 고를 수 있습니다.

## 파일

- `office.html`: Artifact 원본 (문서 뼈대 없음)
- `index.html`: 브라우저용. `./build.sh`로 `office.html`에서 다시 만듭니다.
